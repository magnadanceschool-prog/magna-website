第1章　総則

第1条【名称】

本ダンススクールは「MAGNA DANCE SCHOOL」（以下「本スクール」といいます）と称します。

第2条【適用】

  1. 本規約は、本スクールに入会するすべての会員および体験レッスン参加者に適用されます。
  2. 未成年者が入会する場合は、保護者が本規約を確認し、同意するものとします。
  3. 本規約のほか、各クラス・イベント等について個別に案内する利用条件が適用される場合があります。

第3条【運営管理】

本スクールの運営・管理は、代表 田島慎介（SHiN）が行います。

第4条【目的】

本スクールは、ダンスを通じた技術の向上、健康の維持・増進、心身の健全な成長を図るとともに、会員同士の交流や協調性を育むことを目的とします。

第2章　会員・入会・退会

第5条【会員資格】

本スクール所定の入会手続きを完了し、本スクールが入会を承認した方を会員とします。

第6条【入会手続き】

  1. 入会希望者は、所定の方法で申し込みを行い、別途定める入会金をお支払いいただきます。
  2. 未成年者の入会には保護者の同意が必要です。
  3. 登録内容に変更が生じた場合は、速やかに本スクールへお知らせください。

第7条【入会金】

  1. 入会金は、本スクールが別途定める金額とします。
  2. 納入済みの入会金は、法令上返金が必要な場合または本スクールが特別に認めた場合を除き、返金いたしません。

第8条【退会】

  1. 会員は、本スクールへ申し出ることにより退会できます。
  2. 月額定額制を利用している場合、翌月からの解約を希望する方は、前月末日までにお申し出ください。
  3. 退会時に未使用のチケットがある場合は、その有効期限内に利用することを原則とします。返金が必要となる場合は、契約内容および関係法令に従い対応します。
  4. 再入会の際は、所定の入会手続きが必要となります。

第9条【休会・自動退会】

  1. 会員は、本スクールに申し出ることにより休会できます。
  2. 最終受講日から1年間受講がない場合、本スクールは事前に通知のうえ、会員登録を終了する場合があります。
  3. 休会手続きを行った場合は、手続き時に案内する条件に従い、原則1年間会員資格を維持できます。
  4. 休会期間終了後も受講を再開しない場合は、会員登録を終了する場合があります。
  5. 月額定額制利用者の休会中の料金については、別途案内する条件に従います。

第10条【会員資格の停止・除名】

会員が以下に該当する場合、本スクールは状況に応じて注意、利用停止または除名の措置を講じる場合があります。

  1. 本規約またはスクールのルールに違反した場合
  2. 他の会員、講師、スタッフへの迷惑行為が認められた場合
  3. 暴力、暴言、嫌がらせ、誹謗中傷等を行った場合
  4. 施設や備品を故意に破損した場合
  5. 正当な理由なく料金の支払いを怠った場合
  6. その他、スクールの安全な運営に著しい支障をきたした場合

措置にあたっては、行為の内容や重大性を踏まえて判断します。

第3章　レッスン・料金制度

第11条【レッスン制度】

  1. 本スクールでは、チケット制および月額定額制を設けています。
  2. レッスン時間は原則80分とします。ただし、一部のクラスや特別プログラムでは異なる場合があります。
  3. クラスによって対象年齢、受講条件、定員を設ける場合があります。
  4. 一部のクラスは承認制とし、本スクールまたは担当講師の承認を受けた方のみ受講できます。

第12条【チケット制】

  1. ビジター料金およびチケット料金は以下のとおりとします。
    クラス区分ビジター（当日1回）4回チケット10回チケット
    Kidsクラス（80分）3,500円（税込）12,000円（税込）26,000円（税込）
    50分クラス（18歳以上）3,000円（税込）10,000円（税込）21,000円（税込）
    Childクラス（50分）2,500円（税込）8,000円（税込）16,000円（税込）
  2. チケットの有効期限は、初回使用日から以下の期間とします。
    チケット有効期限
    4回チケット3ヶ月間
    10回チケット6ヶ月間
  3. 原則として1回のレッスンにつきチケット1回分を使用します。
  4. 生徒都合による欠席の場合、未受講のレッスンについてチケットは消化されません。
  5. 有効期限を過ぎたチケットは原則として利用できません。ただし、本スクール都合の休講やその他特別な事情がある場合は、延長等の対応を行うことがあります。
  6. チケットの第三者への譲渡・転売は禁止します。

第13条【月額定額制】

  1. 月額定額制の料金は24,000円（税込）とします。
  2. 受講可能なクラス、受講回数その他の利用条件は、別途案内する定額制利用条件に従います。
  3. 未使用の受講回数の翌月繰越や返金等の取り扱いについては、別途定める利用条件に従います。
  4. 月額定額制の変更または解約を希望する場合は、変更希望月の前月末日までにお申し出ください。

第14条【料金のお支払い】

  1. 入会金、レッスン料金、イベント参加費等は、本スクールが指定する方法でお支払いいただきます。
  2. お支払い方法は、銀行振込、PayPay、現金等、本スクールが案内する方法とします。
  3. 銀行振込に伴う振込手数料は、原則として会員負担とします。
  4. お支払いの確認後にチケットの発行等を行う場合があります。
  5. 月額定額制の支払日・支払方法については、別途案内する条件に従います。

第15条【料金・制度の変更】

  1. 本スクールは、運営状況、会場費、人件費、社会情勢等を考慮し、料金や利用制度を変更する場合があります。
  2. 変更する場合は、変更内容および適用開始日を事前に案内します。
  3. 既に購入済みのチケットや契約済みの定額プランについては、契約内容および関係法令に従い取り扱います。

第4章　レッスン運営

第16条【レッスン会場】

  1. 本スクールは、所定の会場でレッスンを実施します。
  2. 施設の予約状況等により、レッスン会場が変更となる場合があります。
  3. 会員は、受講前に公式ホームページやLINE等で案内される会場情報をご確認ください。

第17条【休講・振替・講師変更】

  1. 以下の場合、本スクールはレッスンの休講、日程変更、会場変更、担当講師の変更等を行う場合があります。
    • 会場の予約状況や利用制限
    • 担当講師の体調不良ややむを得ない事情
    • 台風、地震、積雪等の自然災害
    • 感染症の流行
    • その他、安全なレッスン運営が困難と判断される場合
  2. 休講や変更が決定した場合は、可能な限り速やかに会員へお知らせします。
  3. 本スクール都合による休講については、振替レッスン、他クラスの受講、チケットの補填、有効期限の延長、返金等の方法により、契約内容や状況に応じた適切な対応を行います。
  4. 長期間にわたり特定クラスの開催が困難となった場合は、他クラスの受講をご案内する場合があります。
  5. 代講や担当講師の変更が発生する場合があります。

第18条【欠席・遅刻】

  1. レッスンを欠席または遅刻する場合は、可能な限り事前に担当講師または本スクールへご連絡ください。
  2. 生徒都合による欠席の場合、チケットおよび定額制の受講回数は消化されません。ただし、チケットの有効期限や定額制の利用期間が自動的に延長されるものではありません。
  3. 遅刻した場合でも、原則としてレッスンの終了時間は変更しません。
  4. 安全面から、遅刻の状況によっては途中参加を制限する場合があります。

第19条【クラスの変更・統合・終了】

  1. 本スクールは、受講人数、講師の配置、会場の状況等により、クラスの時間変更、統合、休止または終了を行う場合があります。
  2. 変更が決定した場合は、対象会員に事前にご案内します。
  3. クラス終了等により継続受講が困難となる場合は、他クラスへの移行や未利用料金の精算等について、契約内容に応じて対応します。

第20条【体験レッスン】

  1. 入会前の方は、本スクールが定める条件で体験レッスンに参加できます。
  2. 体験レッスン参加者も、安全管理、禁止行為、撮影等に関する本規約の対象となります。
  3. 未成年者の体験参加には保護者の同意が必要です。

第5章　連絡・写真・動画・SNS

第21条【公式連絡・グループLINE】

  1. 本スクールでは、各クラスの連絡手段としてグループLINE等を利用する場合があります。
  2. グループLINEへの参加は原則任意とします。
  3. グループLINEでは、レッスン日程、休講情報、イベント案内、レッスン動画等を共有する場合があります。
  4. レッスン動画の共有は毎回保証するものではありません。
  5. グループ内で共有された写真・動画・個人情報について、本人または権利者の許可なく外部に公開・転載することは禁止します。

第22条【写真・動画の撮影およびSNS等への掲載】

  1. 本スクールでは、活動記録および広報・宣伝活動を目的として、レッスン中やイベント、発表会等の様子を写真・動画で撮影する場合があります。
  2. 撮影した写真・動画は、本スクールの公式ホームページ、Instagram、TikTok、YouTube、その他公式SNSや広報媒体等に掲載する場合があります。
  3. 写真・動画には、会員の顔や姿、ダンスを踊っている様子、音声等が含まれる場合があります。
  4. 本スクールは、撮影・掲載について本規約等で事前に告知し、会員および保護者のプライバシーや肖像に配慮して取り扱います。
  5. 写真・動画への写り込みやSNS等への掲載を希望されない場合は、事前に本スクールまでお申し出ください。
  6. 掲載を希望されない旨のお申し出があった場合は、撮影範囲の調整、映り込みの回避、編集、掲載対象からの除外等の対応を行います。
  7. 掲載済みの写真・動画について削除等のご希望があった場合は、内容を確認し、本スクールが管理する媒体について適切に対応します。ただし、第三者による保存や転載等については、完全な削除を保証するものではありません。
  8. 写真・動画の掲載を希望しないことを理由に、通常のレッスン受講において不利益な取り扱いを行うことはありません。
  9. 個人を識別できる写真・動画の公開については、関係法令に従い、必要な同意の取得その他の適切な手続きを行います。

第23条【保護者の観覧・撮影】

  1. 保護者によるレッスン観覧は、会場の利用条件やクラス運営に支障がない範囲で認めます。
  2. 写真・動画を撮影する場合は、事前に担当講師の許可を得てください。
  3. 他の会員が写っている写真・動画をSNS等へ公開する場合は、対象者本人または保護者の許可を得てください。
  4. 撮影によりレッスンの進行や他の会員の受講を妨げる行為は禁止します。

第24条【個人情報の取り扱い】

  1. 本スクールは、入会手続き、会員管理、レッスン運営、緊急連絡等に必要な範囲で個人情報を取得・利用します。
  2. 取得した個人情報は、関係法令に従い適切に管理します。
  3. 法令で認められる場合を除き、本人の同意なく利用目的の範囲を超えて個人情報を利用しません。
  4. 写真・動画の利用については、第22条の規定に従います。

第6章　安全管理・禁止事項

第25条【安全管理・健康状態】

  1. 会員は、自身の体調や健康状態に十分注意し、無理のない範囲でレッスンに参加してください。
  2. 体調不良や怪我等がある場合は、受講前に担当講師へお知らせください。
  3. レッスン中は、講師およびスタッフの安全上の指示に従ってください。
  4. 本スクールは、安全に配慮した指導を行いますが、ダンスの特性上、転倒や接触等による怪我の可能性があります。

第26条【禁止行為】

以下の行為を禁止します。

  1. 他の会員、講師、スタッフへの暴力、暴言、嫌がらせ、誹謗中傷
  2. SNS等での悪質な中傷、無断での個人情報の公開
  3. 許可のない営業活動、勧誘活動
  4. 施設や備品の故意の破損
  5. 他の会員のレッスンを妨害する行為
  6. 許可のない写真・動画の撮影や公開
  7. その他、本スクールの安全な運営を妨げる行為

第27条【事故・怪我・盗難等】

  1. 本スクールは、レッスン中の事故防止に努めます。
  2. 会員は、貴重品や私物を自身の責任において管理してください。
  3. 怪我、事故、盗難等が発生した場合、本スクールは状況を確認し、必要な対応を行います。
  4. 本スクールの故意または過失により損害が生じた場合は、関係法令に従い責任を負います。
  5. 会員間のトラブルについても、本スクールの責任が認められる場合には、法令に従って適切に対応します。

第28条【会員による損害賠償】

会員が故意または過失により、本スクール、他の会員、講師、施設等に損害を与えた場合は、法令に従い、その責任の範囲内で損害を賠償していただく場合があります。

第7章　その他

第29条【イベント・発表会】

  1. 本スクールでは、発表会、イベント、外部出演等を実施する場合があります。
  2. 参加費、出演条件、リハーサル日程等は、イベントごとに別途案内します。
  3. イベント参加にあたっては、本規約に加えて個別に定める参加条件が適用される場合があります。
  4. イベントの中止、変更、キャンセルに伴う参加費の取り扱いは、事前に案内する条件および関係法令に従います。

第30条【規約の変更】

  1. 本スクールは、法令に従い、必要に応じて本規約を変更する場合があります。
  2. 規約を変更する際は、変更内容および効力発生日を公式ホームページ、LINE等で事前に案内します。
  3. 変更の効力や会員への適用については、民法その他関係法令に従うものとします。

第31条【協議事項】

本規約に定めのない事項や解釈に疑義が生じた場合は、本スクールと会員または保護者が誠実に協議し、解決を図るものとします。
